## 📋 Overview

SuhuPort is a personal portfolio website demonstrating proficiency in modern web development practices. The project leverages the latest React 19 features with TypeScript for type-safe development, Vite for lightning-fast build performance, and Tailwind CSS for responsive, utility-first styling.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn package manager

### Installation

1. Clone the repository
```bash
git clone https://github.com/DEADPOOLpv/SuhuPort. git
cd SuhuPort
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 📜 Available Scripts

| Script | Description |
